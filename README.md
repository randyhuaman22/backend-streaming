# backend-streaming

API local Node.js para fuentes propias o autorizadas. Configura `SPORTS_BASE_URL`, `MOVIES_BASE_URL` y `ALLOWED_HOSTS` (hostnames separados por comas).

Instala con `npm install`; ejecuta con `npm start` o `npm run dev`. Escucha en `0.0.0.0:3000`. Los catálogos se almacenan 60 segundos.
